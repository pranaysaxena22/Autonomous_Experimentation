# Setup messages

_Generated by `tools/make_setup_messages.py`. Do not edit by hand: change the wording in `cellpoc/setup/messages.py` and run the tool again. The health check fails if this file is out of date._

When a setup has a problem, the setup app shows a message in this form:

> **Screen › Field:** what is wrong and how to fix it

There are three levels:

- **Error**: blocks saving until fixed.
- **Warning**: shown, but does not block saving.
- **Note**: information only.

Every rule below has a test: a deliberately wrong setup that must produce that message. The message shown under each rule is the one the test produced. What the person typed is quoted back in the message (for example `(you wrote '...')`).
