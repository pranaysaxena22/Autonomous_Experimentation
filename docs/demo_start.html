Autonomous formulation cell: demo start

A simulated cell that chooses tablet recipes, runs them, reads the results and learns. One app, one address: this page lists its screens in the order the demo shows them.

ILLUSTRATIVE and SYNTHETIC. Everything here is a simulation with made-up values. There is no real robot, and nothing says anything about real tablets.

Before you start

Double-click run_app.bat and press Enter (option 1). The first time it also draws the MuJoCo view (about two minutes); after that it starts in seconds. Leave its black window open: every link below is a page of that one app, on this computer only.
  • Want the loop-connected version too? Double-click run_app.bat and type 3: it opens at http://localhost:8511 (the first time it can take a few minutes).
  • If a link says it cannot connect, the black window is not running yet.
