# Modelling messages

_Generated by `tools/make_modelling_messages.py`. Do not edit by hand: change the wording in `cellpoc/modelling/findings.py` and run the tool again. The health check fails if this file is out of date._

When a cleaned table is prepared for modelling, the program reports every decision in this form:

> **Table > Result or input:** what happened and what to do

- **Error**: the table cannot be modelled until the problem is fixed.
- **Warning**: rows or inputs were left out, or a result is not modelled. Read these.
- **Note**: facts that every report carries (a balance ingredient left out, rows flagged, an assumed unit, a stand-in for the supplier).

Nothing is ever filled in or guessed silently, and no row is ever moved between training and test data at random. Every message below has a test: a tiny made-up table made to cause exactly that message (the table is called `t` in the tests).
